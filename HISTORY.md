## New editorial design deployed (2026-07-25)
- User dropped `Portfolio website UIUX design.zip` in Downloads = a **design-tool ("dc-runtime") standalone export**: `Portfolio.dc.html` + `support.js` (+ a `.thumbnail`). Replaced the old dark-navy/gold 3-file site with it → **`Portfolio.dc.html` renamed to `index.html`**, `support.js` added at repo root, old **`style.css`/`script.js` removed** (the new page is fully self-contained/inline). Commit `64463b7`, GitHub Pages, verified live ~40s after push.
- **How the dc export works:** `index.html` loads `./support.js` (the dc-runtime), which **dynamically pulls React 18.3.1 + ReactDOM + `@babel/standalone` 7.29 from unpkg** and transpiles the inline `<script type="text/x-dc" data-dc-script>` component at runtime into `<x-dc>`. So it's **CDN-dependent** (needs internet + unpkg up) and uses in-browser Babel — heavier than a plain static build, but it's the tool's official deploy format and renders correctly. All content (hero, stats, about, work, patents, leadership, contact) is inline in `index.html`.
- **Design:** warm paper (#f4f0e7) / ink (#181510) editorial look, Newsreader + IBM Plex Sans/Mono, blue (#2b567f) + warm-orange (#c05a2a) accents, scroll-reveal sections (`revealMotion` prop), film-grain overlay, custom cursor ring. - **Gotchas:** `index.html` and `support.js` MUST live together (relative `./support.js`); a full-page screenshot shows blank bands because scroll-reveal sections are opacity-0 until scrolled into view (they render fine live); 2 harmless console errors (favicon 404 + one malformed grain-texture `data:image/svg+xml` URL). To rebuild/edit the design, re-export from the dc design tool (source is `dc-runtime/src/*.ts` per the `support.js` header) — not hand-editable here. ## Mobile-responsive pass (2026-07-25)
- The dc export ships desktop-only. Made it phone/tablet-friendly by appending a **deploy-only responsive `<style>` block** to the inline stylesheet (commit `75e543c`; user chose to keep the warm "Portfolio" design over a new "Portfolio Studio" variant that was in the re-download). Fixes: (1) fixed-template grids (`200px 1fr`, `180px 1fr[ auto]`, `minmax(0,1fr)` pairs) collapse to a single column ≤760px — the `repeat(auto-fit,minmax())` grids already reflow; (2) top nav link row becomes horizontally scrollable ≤820px (`min-width:0`+`overflow-x:auto`) so all 7 links + Contact stay reachable (they need ~730px); (3) fixed right-edge section-dot rail hidden on mobile (`div:has(> a[data-dot])`); (4) custom mouse cursor (`#__cring`/`#__cdot`) hidden + caret restored on touch via `@media (hover:none),(pointer:coarse)`. Verified live at 390px + 768px; desktop untouched.
- **KEY GOTCHA for any future CSS override:** the dc-runtime (React) **re-serializes every inline style at render** — `grid-template-columns:200px 1fr` becomes `...: 200px 1fr` (space after colon) and `minmax(0,1fr)` becomes `minmax(0px, 1fr)`. So `[style*="..."]` attribute selectors MUST match the **normalized** form (match value substrings like `200px 1fr` / `minmax(0px,`, not the raw source string), and `!important` in the stylesheet is required to beat the inline styles. Element/`:has()` selectors (used for nav + dot rail) are immune to this.
